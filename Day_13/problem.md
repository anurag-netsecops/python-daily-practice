# Day 13 - What's Your Name?

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/whats-your-name/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

You are given a first name and last name on separate lines.

Complete the `print_full_name` function to return:

```text
Hello firstname lastname! You just delved into python.
```

where `firstname` and `lastname` are replaced with the provided values.

---

## Example

### Input

```text
Ross
Taylor
```

### Output

```text
Hello Ross Taylor! You just delved into python.
```

---

## Input Format

The first line contains the first name.

The second line contains the last name.

## Output Format

Return the formatted greeting string.
