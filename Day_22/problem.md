# Day 21 Problem - Alphabet Rangoli

## Problem

You are given an integer `N`.

Your task is to print an alphabet rangoli of size `N`.

A rangoli is a pattern created using lowercase English alphabet characters.

## Input Format

A single integer `N`.

## Constraints

- `0 < N < 27`

## Output Format

Print the alphabet rangoli pattern of size `N`.

## Example

For `N = 3`:

```text
----c----
--c-b-c--
c-b-a-b-c
--c-b-c--
----c----
