# Day 20 Problem

## Text Alignment

You are given a partial code template used to generate the HackerRank Logo with a specified thickness.

Your task is to replace the blank sections using Python string alignment methods.

The HackerRank Logo consists of the following parts:

- Top Cone
- Top Pillars
- Middle Belt
- Bottom Pillars
- Bottom Cone

Use the following string alignment methods:

- `ljust()`
- `rjust()`
- `center()`

## Input Format

The input contains a single integer `thickness`.

The thickness value determines the size of the HackerRank Logo.

## Output Format

Print the HackerRank Logo using the character `H` with the specified thickness.

The output should follow the required alignment and spacing format.
