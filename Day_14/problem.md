---

## Problem Statement

Given a string containing space-separated words, split the string using a space as the delimiter and join the words using a hyphen (`-`).

### Example

Input:

```text
this is a string
```

Output:

```text
this-is-a-string
```

---

## Input Format

One line containing a string consisting of space-separated words.

## Output Format

Return the resulting string with the words joined using hyphens.
