# Day 21 Problem

## String Formatting

Given an integer `n`, print the following values for each integer `i` from `1` to `n`:

1. Decimal
2. Octal
3. Hexadecimal (capitalized)
4. Binary

The four values must be printed on the same line for each integer.

Each value should be space-padded to match the width of the binary representation of `n`.

The values should be separated by a single space.

## Input Format

A single integer `n`.

## Constraints

```text
1 ≤ n ≤ 99
