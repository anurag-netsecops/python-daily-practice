# Day 17 - String Validators

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/string-validators/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

Given a string `S`, determine whether it contains:

1. Any alphanumeric characters
2. Any alphabetical characters
3. Any digits
4. Any lowercase characters
5. Any uppercase characters

Print `True` or `False` for each condition on a separate line.

---

## Example

### Input

```text
qA2
```

### Output

```text
True
True
True
True
True
```

---

## Input Format

A single line containing the string `S`.

## Output Format

Print five Boolean values:

1. `True` if `S` contains an alphanumeric character.
2. `True` if `S` contains an alphabetic character.
3. `True` if `S` contains a digit.
4. `True` if `S` contains a lowercase character.
5. `True` if `S` contains an uppercase character.
