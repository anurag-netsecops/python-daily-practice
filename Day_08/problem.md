# Day 08 - Finding the Percentage

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/finding-the-percentage/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

You are given a dictionary containing student names as keys and a list of their marks as values.

Read the student's name (`query_name`) and print the average of their marks, formatted to **2 decimal places**.

---

### Example

**Input**

```text
3
Krishna 67 68 69
Arjun 70 98 63
Malika 52 56 60
Malika
```

**Output**

```text
56.00
```

---

## Input Format

- The first line contains an integer `n`, representing the number of students.
- The next `n` lines contain the student's name followed by three marks.
- The final line contains `query_name`.

## Output Format

Print the average marks of the queried student, accurate to **2 decimal places**.
