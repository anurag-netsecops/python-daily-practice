# Day 18 - sWAP cASE

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/swap-case/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

Given a string, swap the case of every character.

In other words:

- Convert lowercase letters to uppercase.
- Convert uppercase letters to lowercase.
- Leave numbers and special characters unchanged.

---

## Example

### Input

```text
HackerRank.com presents "Pythonist 2".
```

### Output

```text
hACKERRANK.COM PRESENTS "pYTHONIST 2".
```

---

## Input Format

A single line containing a string `s`.

## Output Format

Return the modified string with the case of each alphabetic character swapped.
