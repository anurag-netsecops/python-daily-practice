# Day 11 - Find the Runner-Up Score!

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/find-second-maximum-number-in-a-list/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

Given the participants' scores, find and print the **runner-up score**.

The runner-up score is the second-highest **unique** score.

### Example

Input:

```text
5
2 3 6 6 5
```

Output:

```text
5
```

### Explanation

The scores are:

```text
[2, 3, 6, 6, 5]
```

The highest score is `6`.

After removing duplicate scores:

```text
[2, 3, 5, 6]
```

Therefore, the second-highest or runner-up score is:

```text
5
```

---

## Input Format

- The first line contains an integer `n`.
- The second line contains `n` space-separated integer scores.

## Output Format

Print the runner-up score.
