Easy

---

## Problem Statement

Given a string, change the character at a specified index and return the modified string.

The `mutate_string` function accepts:

- `string` - the original string
- `position` - the index where the character should be changed
- `character` - the new character

---

## Example

### Input

```text
abracadabra
5 k
```

### Output

```text
abrackdabra
```

The character at index `5` is replaced with `k`.

---

## Input Format

The first line contains a string.

The second line contains an integer `position` and a character, separated by a space.

## Output Format

Return the modified string.
