# Day 19 - Text Wrap

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/text-wrap/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

Given a string `S` and a maximum width `w`, wrap the string into multiple lines where each line contains at most `w` characters.

The function should return the resulting string with newline characters (`\n`) between the wrapped lines.

---

## Example

### Input

```text
ABCDEFGHIJKLIMNOQRSTUVWXYZ
4
```

### Output

```text
ABCD
EFGH
IJKL
IMNO
QRST
UVWX
YZ
```

---

## Input Format

The first line contains a string `string`.

The second line contains an integer `max_width`.

## Output Format

Return the wrapped string with newline characters between the lines.
