# Day 16 - Find a String

## Platform

HackerRank

## Problem Link

https://www.hackerrank.com/challenges/find-a-string/problem?isFullScreen=true

## Difficulty

Easy

---

## Problem Statement

Given a string and a substring, find the total number of times the substring occurs in the original string.

The string should be traversed from left to right.

Substring matching is case-sensitive.

Overlapping occurrences should also be counted.

---

## Example

### Input

```text
ABCDCDC
CDC
```

### Output

```text
2
```

The substring `CDC` occurs twice in `ABCDCDC`.

---

## Input Format

The first line contains the original string.

The second line contains the substring.

## Output Format

Print the total number of occurrences of the substring.
